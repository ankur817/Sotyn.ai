## 1. Google Search Console — status and setup

**Not yet verified.** There was no `google-site-verification` tag, no
`google*.html` file in `public/`, and no DNS TXT wired into the repo.

A verification slot is now in place (see CHANGE LOG below). Two routes:

### Route A — Domain property (recommended)
Covers `sotyn.ai`, `www.sotyn.ai`, `http://` and every subdomain in one property,
and survives redeploys because it lives in DNS, not in the build.

1. Search Console → Add property → **Domain** → enter `sotyn.ai`
2. Copy the TXT record Google shows (`google-site-verification=...`)
3. At the DNS host for sotyn.ai, add: type `TXT`, name `@`, value = that string
4. Wait for propagation, then click Verify

### Route B — HTML tag (fallback / second property)
1. Search Console → Add property → **URL prefix** → `https://www.sotyn.ai`
2. Choose "HTML tag", copy **only the token** from `content="..."`
3. Paste it into `src/config/site.ts` → `googleSiteVerification`
4. Deploy, then click Verify

### After verification
- Submit `https://www.sotyn.ai/sitemap-index.xml` under Sitemaps
- Set the international target to India (or leave auto — `en-IN` is already declared)
- Request indexing for `/`, `/pricing`, `/epc-erp-software`, `/demo`
- Also verify the apex as its own property if you use Route B, so the 308 is visible

### Issues found

**1. Titles over 60 characters — 28 of 41 pages. → FIXED.**
Longest were `/tools` (99 chars) and `/resources` (97). All 41 indexable pages are
now ≤60 characters, with no duplicates introduced.

> Correction to the first pass of this report: it said *31* titles and measured
> them in **bytes**. `—` and `₹` are 3 bytes each in UTF-8, so those figures were
> inflated. The character counts above are the correct ones.

**2. Meta descriptions over 160 characters — 32 of 41 pages. → FIXED.**
Longest were `/pricing` (273 chars), `/platform` (267) and `/about` (257). All 41
are now ≤160, most at 130–155.

**3. No analytics or GSC-linked measurement.** There is no GA4 / gtag on the site
and `metaPixelId` is empty, so once GSC is verified you will have search-side data
with nothing to join it to on the site side.

**4. Render-blocking Google Fonts stylesheet** in `<head>` (Anton + Inter
variable). `preconnect` is already there; `display=swap` is set. Self-hosting the
two families would remove the third-party round trip — optional, low priority
given the 0.25 s TTFB.

**5. No `hreflang`.** Correct today (single `en-IN` site). Only relevant if you
add regional or Hindi variants.

### Not blocking, worth noting
- `/demo`, `/webinar`, `/scorecard` are conversion pages that are indexable — fine,
  but they will pull branded queries away from `/`. Watch in GSC once data lands.
- `sales@sotyn.ai` is marked ⚠️ REPLACE in config; the schema uses
  `emailFallback` (`sales@securedengineers.com`), so structured data is consistent.

results. It is now not. **If DECISION 4 resolves as "11 languages are live",
put it back** — there is room at 136 characters.
