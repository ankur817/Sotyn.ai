## 1. Google Search Console — status and setup

**Not yet verified.** There was no `google-site-verification` tag, no
`google*.html` file in `public/`, and no DNS TXT wired into the repo.

A verification slot is now in place (see CHANGE LOG below). Two routes:

### Route A — Domain property (recommended)
Covers `sotyn.ai`, `www.sotyn.ai`, `http://` and every subdomain in one property,
and survives redeploys because it lives in DNS, not in the build.

1. Search Console → Add property → **Domain** → enter `sotyn.ai`
2. Copy the TXT record Google shows (`google-site-verification=...`)
3. At the DNS host for sotyn.ai, add: type `TXT`, name `@`, value = that string
4. Wait for propagation, then click Verify

### Route B — HTML tag (fallback / second property)
1. Search Console → Add property → **URL prefix** → `https://www.sotyn.ai`
2. Choose "HTML tag", copy **only the token** from `content="..."`
3. Paste it into `src/config/site.ts` → `googleSiteVerification`
4. Deploy, then click Verify

### After verification

## Do NOT use the automated GoDaddy flow (recommended)

Search Console auto-detects GoDaddy and offers "START VERIFICATION", which runs
GoDaddy **Domain Connect**. That template's scope is
`domain-verification+gmail-setup` — it can write **MX records**, not only the
verification TXT. On a domain whose email you already run, that is an unnecessary
risk. The manual TXT record above changes nothing except verification.

A Domain Connect tab may still be open in Chrome from this session. It is inert
(GoDaddy was never signed into) — just close it.

## Code prepared while blocked

`SITE.analytics` now has two **mutually exclusive** slots, because
`lead-and-analytics-spec.md` §2 says *"One stack only. Do not add a second tag
manager or a duplicate GA4 tag."*

- `ga4MeasurementId` — `G-XXXXXXXXXX`, loads gtag.js directly. Simplest.
- `gtmContainerId` — `GTM-XXXXXXX`, loads GTM; configure GA4 **inside** GTM.

on and no PII is passed, per spec §2. `tests/analytics.test.mjs` asserts the
mutual exclusion, both ID formats, that nothing fires unconfigured, and that the
GSC slot holds a bare token rather than a whole meta tag.
